# Complexity

It's useful to define 'complexity' as a way to 'solve problems', as 'simplicity/complexity' is a component of 'ir/relevance'.


## Complexity structures

Structures of complexity include:
- irreducibility/uncontrollability/unchangeability/unconnectability
- instability ('stability' being a 'limit' structure of 'complexity')
- randomness/disorganization/ambiguity of alternatives
- distant/indirect/independent connections


## Complexity intents

Unsolved intents related to 'solving complexity' include:
- identifying 'maximally complex' structures that can connect relevant graphs
- identifying 'maximum ratios of complexity structures' that can fit in a relevant graph
- identifying optimizations applied to complexity structures to identify graphs of 'multiple/independent/unique/otherwise optimal' complexity structures
- identifying graphs that generate all relevant structures (limits/variables/components/inputs) of complexity
- identifying graphs that 'solve all complexity structures' like by 'connecting all complexity structures to simplicity/stability/limit structures'
