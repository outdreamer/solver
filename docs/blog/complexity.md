# Complexity

It's useful to define 'complexity' as a way to 'solve problems', as 'simplicity/complexity' is a component of 'ir/relevance'.


## Complexity structures

Structures of complexity include:
- irreducibility/uncontrollability/unchangeability/unconnectability/unstandardizability
- instability ('stability' being a 'limit' structure of 'complexity')
- randomness/disorganization/ambiguity of alternatives/uncertainty/lack of structure/indescribability/immeasurability/unverifiability (not being directly connectible to defined structures, but rather depending on 'sequences of inferences')
- distant/indirect/independent connections

'Optimized' complexity involves 'applying optimizations to complexity', generating structures like:
- maximally 'stabilized' complexity
- 'irreducible' complexity (complexity units)
- complexity implementing 'multiple' complexity structures
- 'causative/multiple' complexity generators

Complexity errors include:
- complexity limits
- false complexity
- irreducible differences/randomness/other variables/variants of complexity
- missing identified interactivity with interface variables (interactivity that often simplifies complexity)
- lack of relevant concepts/graphs ('graphs of concept definitions' often trivializing 'solving a problem' by changing it into a 'matching concept/type/graph identification' problem) or relevant functions (which trivialize 'solving a problem' like by 'generating larger steps to reduce a sequence to fewer steps')
- lack of relevant definitions of optimality/relevance (identified 'definitions of optimality/relevance' are 'insufficiently specified/otherwise varied' to trivialize 'simpifying/reducing some complexity structure')


## Complexity intents

Unsolved intents related to 'solving complexity' include:
- identifying 'maximally complex' structures that can connect relevant graphs
- identifying 'maximum ratios of complexity structures' that can fit in a relevant graph
- identifying optimizations applied to complexity structures to identify graphs of 'multiple/independent/unique/otherwise optimal' complexity structures
- identifying graphs that generate all relevant structures (limits/variables/components/inputs) of complexity
- identifying graphs that 'solve all complexity structures' like by 'connecting all complexity structures to simplicity/stability/limit structures'
