# Consciousness


## Definition

It's useful to define/specify consciousness further, beyond a simple definition like 'capable of understanding'.

To be 'conscious' is approximately to be 'aware', as in 'being able to tell/sense/see (identify) some structure', so a brain that 'regularly' applies an 'identify' function as a node/connector is a brain that can be 'conscious' of regular subsets of itself.

A more complex variant of 'identify' as a 'consciousness function' includes an 'evaluate/analyze function' (a brain that 'tests or evaluates or judges' a structure is 'conscious' of that structure), so a brain that identifies a structure and also evaluates/analyzes/judges it accurately/realistically (such as 'alternating between these functions') is a more conscious brain than one that merely applies 'identify' regularly.

Extending this to include 'understanding' is similarly valid (a brain that 'understands/comprehends' as in 'can optimally apply' a structure is 'conscious' of that structure). A brain that analyzes a structure enough to generate understanding (being capable of optimally using a structure, bc its relevant interactions are understood) applies 'analyze' functions iteratively until 'relevant interactions are identified' (as opposed to just alternating identify/analyze).

Expanding this to include definitions of consciousness including high-level functions (such as 'self-awareness' and 'self-optimization' and 'self-organization') can be done by applying implementations of identify/analyze to generate these high-level functions, or changing function inputs to allow identifying/evaluating mind structures like a 'concept of self' and a 'compressed copy/relevant subset of the mind'.

Other core functions expand the potential functionality of connections, such as by integrating core functions like 'change/apply/filter/define/describe/aggregate/average/compress' to support functions like 'simulate' which are useful for understanding.

The structure of the brain (and which nodes/functions it applies/implements) filters how a specific definition of consciousness can be implemented.
