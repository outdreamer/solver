# AI Risks


## General Risks

General AI risks (or general problem-solving risks) include general errors such as:
- implementing required intents, in an unintended/irrelevant/useless way
	- implementing an irrelevant subset/structure of required intents
- failing to implement required intents
- failing to identify missing/imbalances/other errors of optimal required intents
- implementing required intents with incorrect solution metric 'sequences/other structures'
- implementing required intents with suboptimal definitions/concepts/interface structures


## Optimizations/solutions to offset errors

Identifying the following structures can offset these general risks of errors:
- graphs applying these errors as 'boundaries/structures to avoid'
- general solution structures opposing each general error structure (optimized like by 'identifying overlapping/integratable/coordinating solutions')
