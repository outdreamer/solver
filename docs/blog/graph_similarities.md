# Graph Similarities


Graphs are valuable for identifying new graphs/connections/similarities, based on a defined/generative graph connection/similarity.


## Graphs/similarities emerging from defined similarities of a graph

Emergent/new/implicit/unidentified similarities can be identified/generated by 'queries' that compose/sequence defined/explicit/direct/adjacent similarities like '1-degree node connections' in a graph, where the query does a 'large ratio of the work' by composing/sequencing 'many/maximally different/complex/relevant/otherwise non-trivial steps of trivial node connections'.

The 'defined similarity' and the 'emergent similarity' have the '1-degree/otherwise trivial node connection' structure in common; the defined similarity generates the connection, and the emergent similarity applies the connection to generate other connections.

For example, a suboptimal/partial 'relevance network' can emerge by applying 'simple structural similarities (like common root words)' to generate core connections in a graph.

In this way, new graphs (as layers/subsets/connections/structures of the defined graph) emerge from the generated/defined/intended graph.

Identifying 'alternate definitions of a graph' can be useful to identify 'emergent graphs of a graph', by identifying what is defined/undefined, based on the alternate definitions.


## Differing directions of the intent/structure connection

Queries of a graph are 'composing/sequencing "similar/causal/otherwise connected" structures/functions' to implement intents, which is the opposite direction as opposed to 'applying specifications/implementations of intents/similarities', which is what was applied to generate the graph (as in 'apply this intent/similarity to generate the graph, so that queries using that intent/similarity can compose/sequence functions/structures into new intents/similarities').


## Graph intent sequences

The initial valuable intent of a graph is to 'identify the similarities that will emerge as composable/sequenceable, with queries of a graph generated by different similarities'.

Intents like the following are useful to implement next, to identify the emergent 'optimization/integration' similarities enabled by the emergent 'composable/sequenceable similarities, enabled by the generative similarities':
- 'identify similarities that will optimize the graph'
- 'integrate the graph with other relevant graphs'
