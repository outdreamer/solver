# Useful Perspectives

Useful perspectives have variables in common, including that they:
- are meaningful (they apply meaning/relevance/optimization/usefulness/importance in some relevant way, like a new/unique/simplifying/powerful/independent/causative way)
- represent a combination/connection/sequence/structure of 'optimization metrics' as 'priorities of the perspective'
- represent reality to some degree, with realistic degrees/structures of complexity/other interface variables
- solve a problem (connect errors/solutions) to some degree/in some way
- are maximally different like 'different on multiple interfaces, in structures that are different in multiple ways like "multiple differences that are defined/applied/embedded/implemented/optimized"' from base perspectives like 'adjacent/trivial/simple/core perspectives'
- are components/inputs/causes/structures of other useful perspectives

Useful perspectives can be more useful when:
- any of the above variables are optimized (like 'maximized')
- connected to other perspectives in a graph, like integrated into the same perspective as other useful perspectives
- applied in structures like 'degrees' (applying a 'degree' of a perspective to another perspective)
