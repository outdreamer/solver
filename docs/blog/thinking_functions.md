# Thinking Functions

Thinking types/functions are useful to identify/specify/define. 


## Thinking function variables

- mind interactions: whether some ratio of the mind is required to implement a thinking function, whether a thinking function optimizes the mind it's being applied in, etc
- thinking interactions: thinking functions that enable/invalidate other thinking functions/types, whether thinking functions can be applied simultaneously, thinking functions that optimize thinking, etc
- structure interactions: thinking functions that generate/optimize/apply mind structures/graphs


## Thinking function examples

Core function thinking
- identification/generation/connection thinking functions can be implemented with standard mind structures, like 'function networks'
- these core functions are interface functions (all problems can be solved by applying 'identification' functions), so this thinking function type is a component of interface thinking
- thinking functions are associated with a 'perspective/standard/priority' (like how 'requirements' are a priority in 'requirement-based thinking'), a perspective which is associated with a graph (applying 'requirement-based thinking' applies a 'requirement' standard to generate a graph that 'regularly includes/implements/represents requirements, or otherwise applies the standard')

Organized thinking
- organized (network/graph) thinking can be implemented with organization structures like 'relevant graphs'

Implementation thinking
- implementation (specification) thinking is an expensive process that tends to prevent other types of thinking by taking a lot of mind resources

Required thinking
- regularly applying 'questions as filters' or 'answers/solutions as targets/intents' is an example of required thinking (applying requirements to thinking like 'regularly required thoughts')

Planned thinking
- planned (sequential) thinking involves 'optimizing for intents in intent sequences'

Optimization thinking
- optimization thinking involves applying changes to generate an increase/decrease in some metric (which is a thinking type that applies a filter, like to 'identify a specific useful variant of a structure')


## Optimal interactions of thinking functions

Optimized thinking
- optimized thinking implements 'interface thinking' like 'thinking about solving multiple problems at once or solving relevant problems like graph problems'
- interface thinking can be generated with combinations of other thinking functions
