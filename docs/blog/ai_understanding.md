# AI Understanding

AI is a complex space of network interactions, but frequently these interactions are sufficiently similar/different at scale (or with other interface applied) to be identifiable.


## Possible Interface Structure Variants

There are many possible interface structures that can be used to understand AI.

- relevance operations: structures with 'additive relevance/meaning', so they can be combined to generate 'already understood meanings'
- abstract similarities of sequences: abstract similarities connecting relevant sequences (from 'core matrix operations to resulting solution relevance', or from 'raw data to patterns', or from 'network implementation to network organization/optimization') which cover sufficient variation through their abstraction to be simple enough to understand just by understanding the abstract similarity interactions
- concepts and relevance: new AI concepts (like connecting 'data patterns to neural network limits' or 'matrix operations/states to solution patterns') and the relevance of those concepts
- problems/limits of solutions/possibilities: abstract definition structures (like limit/requirement/constant structures), which identify what AI is not capable of and what AI is not, to define a 'possibility space' of what it can be

Optimizations can be applied to identify more specific solution structures to identify:
- a mix of multiple interface structures is likelier to be relevant than one type, so the solution should have more than one of the above interface structure types.
- variation/complexity matching should be applied (as well as other validity checks) when identifying abstract similarities or new concepts
- integrating the structures with relevance of their interactions is likelier to be more useful than analyzing them in isolation
