# Self-optimizing AI

'AI that optimizes itself' is a useful intent.


## Example implementation intent sequences

Implementation intent sequences include:
- identify useful current AI implementations, then generate changes in probable useful directions given a subset of identified useful change direction, then implement to some degree, then identify errors with that implementation, then identify optimal intents to optimize for instead of implementing further, then vacillate between 'intent implementation and identifying intents' until some new optimal implementation is identified (this is suboptimal, because it's a very irrelevant/simple method that doesn't apply the definition of relevance as a regular filter/component, and it assumes without cause that existing implementations form a useful base to apply changes to)
- identify relevant graphs of existing/adjacent/theoretically possible AI implementations which make 'useful change directions' more relevant (like by being useful across multiple/important graphs), which is a more optimal method than the above 'trial and error-based method'
- identify variables of AI implementations and structures of variables (like 'coordinating variable value sets') and connect these structures of variables with 'probable error types and optimizations for those error types'
- generate maximally different AI implementations and identify connections between each implementation and every general error type and invest more in implementing/optimizing the implementations which less trivially/relevantly connect to multiple/important/relevant error types
- generate relevant graphs of 'useful intents to optimize AI implementations for' and apply this or similarly relevant sets of graphs as a 'requirement boundary on a possibility space' to change/filter implementations in that possibility space


## Useful variants of self-optimizing AI

Useful variants include:
- AI that generates/tests/analyzes itself
- AI that learns optimization specifically
- AI that organizes/controls/optimizes/graphs/identifies other optimal AI implementations optimally
- AI that optimizes for alternative functions like 'infer/predict/derive/imply/require/define' as opposed to 'learn/depend'
