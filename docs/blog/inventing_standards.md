# Inventing Standards

'Any combination of structures' can't be considered an invention, so filters like 'standards/definitions' need to be applied to identify real inventions.

Applying interfaces (like 'cause') and the definition of 'relevance' (like components such as 'relevant across multiple intents'), is useful to identify these standards for inventions.

Inventing inventions is similar to generating a new story:
https://github.com/outdreamer/solver/blob/master/docs/blog/story_ideas.md


## Relevance

Non-triviality
- a trivial combination of identified/existing structures can't be an invention, because it could easily just be an error

Usefulness
- an invention is useful for some intent, where the intent is also useful, like useful for 'generating other inventions' or useful for 'generating useful graphs'

Optimality
- an invention should be optimally implemented/defined, rather than just any definition/implementation qualifying as an invention

Independence
- the invention should rely on other inventions as little as possible to be considered a real invention, and should inspire other inventions


## Interfaces

Cause
- the reason why an invention is useful is identified, because an invention that is not understood is not as useful as an invention that is understood, including understanding its causality.

Difference
- the invention should be extremely different from existing resources, and also extremely different from other inventions

Logic
- the invention should apply rules of logic to identify new rules of logic or new definitions

Problem/Solution
- an invention should solve any problem, and should solve problems in a new way, in order to be a real invention
- the invention should have new errors than other inventions have

Structure
- the invention should be different in 'multiple' ways, like in multiple interface variables
- the invention should have different structures, like different 'combinations/sequences/limits', than other inventions


## Invention completeness

An invention can be considered complete when:
- its definition is specified, differentiating the invention sufficiently from other structures as to be identifiable
- examples of implementations of the invention are specified, or examples of variables of implementations are specified
- optimizations of the invention, or its optimal implementation, are specified
- the invention is sufficiently different from other inventions and otherwise qualifies as an invention given the definition above
