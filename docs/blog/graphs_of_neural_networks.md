# Graphs of Neural Networks


## Graphs learnable by neural networks

The 'graphs learnable by a neural network' refers to the 'relevant graphs that a neural network can learn', given its ability to learn relevant graph nodes such as 'concepts/functions/interface structures' and its ability to connect nodes in the way the relevant graph connects them, like by 'sequences of vectors', where vectors can have 'local relevance' (so that one vector in one position of a neural network has the meaning of 'connecting this structure and this function on this relevant graph' and another vector in another position with the same value as the other vector has the meaning of 'connecting a structure set in a different relevant graph'). 

A 'spectrum of relevance implementation' is reflected in the relevance structures learnable by a neural network, in the explicitness/implicitness of the relevance learnable in the network - some networks can only learn vectors that reflect 'vectors on other relevant graphs, organized chaotically by chance and necessarily incomplete', whereas other networks can learn the 'complete structure of the other relevant graphs, organized the same way as the relevant graph'.

The 'relevance learnable by a neural network' is reflected in the 'graphs learnable by the neural network'.

'Variables of relevance' need to be reflected in the neural network structure in order for it to be an 'optimal learning network', like 'allowing updates' or 'regularly generating/filtering updates' (reflecting the 'newness' variable of relevance).

The graph of 'relevance variables/structures learnable by a neural network' is a graph that approximately reflects the 'graph of the ethics/optimality of a neural network', bc the 'graph of relevance learnable by a neural network' indicates how ethical/optimal the neural network can become. If a 'subset of relevance' is learnable by a neural network, it has an upper limit on the ethics/optimality it can learn.

The 'graphs learnable by a neural network' can differ in graph variables, like 'connection variables like "multiple directions of a connection"', 'connection type (like function type, function alignment, spectrum/sequence/function/similarity)', 'node type', and 'generative variables'.


## Graphs of neural networks


### Ethical graph of interface variables of a neural network

The graph of the 'ethics' of a neural network is a relevant graph of a neural network - this is the graph of what a neural network identifies as 'optimal interaction rules between concepts' (like 'when power is centralized, stop prioritizing power and start prioritizing balance of power'). 

This graph associated with a neural network will likely be an incomplete/otherwise suboptimal reflection of the optimal ethical system, the 'system of optimal interactions between interface variables'.

Identifying 'required subsets/structures of the optimal ethics network that a neural network should be capable of learning, and which it does learn across varied data sets, in order to be considered a valid problem-solving network' involves the system of ethics/optimization of 'neural network/graph/interface interactions'.


### Optimization graph of a neural network prediction model

The 'system of optimal interactions between interface variables' (the global ethical network) should emerge naturally from a valid problem-solving neural network, as a system that is useful for solving problems, which any valid problem-solving neural network should identify across varied data sets. This involves not just 'predicting an output from an input', but 'optimizing the path to the output from the input' and 'optimizing the input/output'. So while identifying a 'prediction/causality graph of variables', an 'optimization graph of the prediction/causality graph' should be updated/generated simultaneously/at regular intervals.

The 'system of optimal interactions between interface variables should emerge naturally from a neural network' means that if a neural network 'predicts the probable/common/similar end of a sentence', it should also 'predict the systemically optimal end of the sentence' (the optimal variant of the interaction should be identified, given a system of ethics/optimal interactions) and 'predict the optimal ends of any beginning sentences' (all optimal interactions should be identified), and these optimal interactions should be prioritized interactions in the model, until optimization is complete given available data and there are only optimal interactions in the model.
