# Graph Embeddings


Graph embeddings apply an identified similarity to position items in a graph.


## Standard graph embedding functions

Standard graph embedding functions include:
- identifying similarity by trivially changing an item to identify adjacent items
- positional adjacency in a graph
- number of alternate connections between a pair of nodes in a graph


## Other graph embedding functions

Other graph embedding functions include:
- apply an identified graph to identify similarities on, like 'within n steps' or 'connectible by hub nodes' or 'connectible by unique paths'
- apply spectrum variables like 'abstraction' to generate similar items by 'similar abstraction level' or generate similar items by 'similar abstraction sequence'
- apply a relevant graph of similarities, like a similarity index graph, to identify similar items


## Relevant graph embedding functions

Relevant graph embedding functions apply similarities that are relevant like:
- similarities that are relevant/stable, with no identified relevant/contradictory differences (a 'connection with n steps' is also similar in other graphs like 'connectible by abstraction' or in other ways like 'connectible by many different routes of n steps')
- similarities that are optimal, like similarities to optimization structures
