# Integrations

Integrations of interface structures are relevant because they involve identifying important structures like 'connections/similarities' between interface structures, often across interfaces. 

Integrations of graphs are specifically relevant because graphs can generate new interfaces like 'relevant graphs'.


## Graph Integrations

'Graph integrations' are useful as a way of connecting relevant graphs in one graph, in ways other than by applying 'meta graphs, as in graphs of graphs'. 

Other graph connection types include 'graph sequences' and 'iterations of interface graphs of graphs, until graphs overlap or are otherwise similar'.

Graph integrations can combine any set of graph structures, like graph positions/nodes/layers/axes/spectrums/queries/limits/generators/connections/directions, from different graphs to create a mixed graph.

Graph structures can be integrated at different positions on a graph generation/optimization sequence.

Relevant graph integrations connect relevant graphs, like integrating a 'relevant graph' with an 'optimization graph'.

A reason for isolating graphs is to allow enough differences to identify new connections between/variables of different graphs. Similarly, a reason for integrating graphs is to identify relevant similarities across different graphs that can interact optimally within a graph's system of interaction between its variables.

Integrating graphs can implement an intent like 'identify the optimal system of interaction rules between graph variables'. This system would include relevant interactions between interface structures, like applying 'causal variables to generative graphs of a graph'.


## Other Structure Integrations

Structures should be integrated when they have similar inputs/outputs/intents/other interface structures.

For example, an optimization graph and an optimization optimization graph have similar possible intents like 'identify optimizations', so these graphs can be connected/integrated by this intent, like by identifying the structures of each graph that optimally implement the intent.

This is a way of generating 'graphs of relevant structures', like to solve the problem of 'identifying when to stop applying interface analysis'. It applies a filter of 'apply interface analysis, until there are no relevant similarities to integrate structures into new relevant graphs', as opposed to other filters like 'apply interface analysis, until sufficient differences are identified to generate new relevant graphs'. Identifying 'sets of relevant structures' can be connected in a graph, a graph that can be applied as a 'filter of intents to implement' (as in 'implement the structures/intents possible on that graph').
