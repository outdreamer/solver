# Graph Structures


## Math structures of a graph

Examples of math structures on a graph:
- convolutions of interface variables in a graph's structures (like its generative variables, optimizations, relevant points, graph intents, graph sequences), like all the ways complexity/variation can interact in a graph's structures
- sheaves of a graph which implement constant/certainty structures of a graph as specifications and variables/uncertainty structures as abstractions, the specifications/abstractions of a sheave
- kernel functions of a graph which reduce it to equivalent lower-dimensional graphs
- the fourier transform of a graph which isolates the component graphs of a graph
- spectrums/axes on a graph are often useful to apply/identify, to apply a range of values like a 'range of complexity/abstraction' to a graph

Examples of math structures of graphs:
- graphs of graphs
- queries of graphs of graphs, like 'waves of graphs' (as in a 'query alternating between extremes on a spectrum graph of graphs')
- spectrums/sequences/combinations/integrations of graphs


## Interface graphs of a graph

Examples:
- the limit graph of a graph, the optimization graph of a graph, the interface graph of a graph, and the graph of relevant interactions like 'prioritized sequences' of these interface graphs

Interface graphs can be applied as graph layers, a layer of surrounding graphs, a set of points on a graph, or other graph structures of a graph


## Interface structures on a graph

What interfaces look like on a graph:
- interfaces can look like intersecting spectrums on a graph, to indicate relevant similarities/bases that identify/generate a graph

What problems look like on a graph:
- problems can look like 'maximally distant nodes' of a graph, since a problem would be to 'connect maximally different nodes of a graph trivially/otherwise relevantly'
- problems can also look like disorganizations, false equivalences/differences, missing nodes/connections, over-densities, over-prioritizations/optimizations for an irrelevant metric, and other problem structures

What problems look like on a neural network:
- problems in a neural network look like 'inactivated/useless nodes', 'subsets of nodes/weights/layers which are active but dont relevantly change the output', 'suboptimal sequences/positions of weights/layers/nodes', 'suboptimal function sequences that could be more efficient', 'incomplete function sets which dont apply interface analysis', 'missing change types that could generate additional functions', 'nodes/weights that often cause errors like over-fitting'

What perspectives look like on a graph:
- perspectives can look like graph layers, angles of a graph which identify differences in the graph, or variants of a graph
