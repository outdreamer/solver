# AI/Math/Interface Inventing Rubric/Homework

Learn and apply the following to become an AI/math/interface inventor/automator:

1. interface: learn the list of primary core interfaces and the definition of an interface

2. math: learn the ~100 basic math concepts in data science/statistics/machine learning, so you can specify/implement your conceptual understanding ('connect concepts to the math interface', as in 'specify/implement concepts')

3. concept: learn how to identify conceptual interactions like 'abstract similarities'

4. specification: apply specifications of concepts to connect to the math interface (to be able to 'find a math function that specifies/implements this concept set')

5. graph: learn at least ~10 relevant graphs, to be able to trivially/otherwise relevantly identify/generate other relevant graphs to solve problems, such as the following:
- the concept structure/combination similarity/optimality graph
- the graph of the definition of relevance
- a graph of maximal differences (like 'maximally/relevantly different concept combinations' or 'maximally/relevantly different cross-interface structures') as an 'inventing/creativity graph'
- the similarity index graph
- a graph of relevant graphs
- a graph of maximally relevant structure interactions (like problem/solution types/structures/variables)
- a graph of interface structures (or a graph of interface structures of interface structures)
- a graph of defined/required/constant interactions between graph variables/similarities, graph definitions, graph intents, graph problems, and other graph interface structures
- a graph of optimal interactions between implementation structures like 'causal/interface connection types between graph nodes' and 'graph specifications'
- a graph of optimal interactions between applications/implementations/queries of a graph of queries/workflows/intents
- a graph of optimal interactions between graph optimizations
https://github.com/outdreamer/solver/blob/master/docs/blog/relevant_graphs.md

6. network: learn at least ~10 neural network types, what their concepts (abstract variables/similarities) are, what problems they solve, their limitations, how they connect to the math interface, and why they work - as a useful specification of the 'graph' interface to apply
https://github.com/outdreamer/solver/blob/master/docs/blog/descriptions_neural_networks.md
https://github.com/outdreamer/solver/blob/master/docs/blog/neural_network_errors.md

7. change: apply changes like 'different combinations' of neural network concepts (or neural network algorithms/parameters/structures) to 'technically' invent AI

8. relevance: learn and apply the definition of relevance to be able to optimize AI inventions ('optimize' as in 'implement the definition of relevance'), to relevantly as in 'meaningfully/importantly/usefully/optimally' invent AI
https://github.com/outdreamer/solver/blob/master/docs/blog/relevant_graphs.md
https://github.com/outdreamer/solver/blob/master/docs/blog/inventing_standards.md

9. apply: regularly apply thinking about intents like 'integrate these relevant graphs', 'identify iterations/applications/organizations of these concepts' and other interface intents, so that more interface intents are trivial/otherwise relevant for you to apply, so that your brain has a 'relevant graph/variable/interface/other interface structure in each neuron' and you regularly 'optimize connections between neurons' by thinking about cross-interface structures like 'graph interactions'

Other interfaces (intent/function/logic/definition/information/potential) are useful to learn to at least a basic degree as well, but the above steps implement one relevant workflow to learn how to become an AI/math/interface inventor.
