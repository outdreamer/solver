# AI Problem Sequence

The intents (to solve specific problems) of AI inventions have followed a sequence that is often causal, enabling building on previous inventions.


## Multi-layer perceptron

The intent of the multi-layer perceptron was to solve the problem of 'adding non-linearity to a system to find a function'.


## Classification algorithms like CNNs

CNNs were intended to 'find an abstraction/type/class from similar/adjacent info'.


## Reinforcement learning

Reinforcement learning algorithms were intended to learn a 'spectrum of accuracy' by assigning 'higher rewards to more accurate outputs' to identify 'more accurate outputs'.


## SVMs

Support vector machines were intended to 'differentiate clusters/classes'.


## Transformers

Transformers were intended to predict the end of a sentence from the beginning of a sentence, enabling other intents like 'predict the output solution for an input problem'.


## General intents and variants of general intents

General intents like 'add a relevant interface variable (like an "opposing variable like generality of specificity", or "non-linearity") to a system to find functions' and 'find an interface structure (like a problem/abstraction) from a similarity (like adjacency)' are the general variants of these algorithms.

Variants like 'integrations' of these intents are possible, like 'add a relevant interface variable to a system to find solution-causing functions'.
