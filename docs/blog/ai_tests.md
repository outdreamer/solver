# AI Tests

'Tests/evals of AI models' are useful to identify and apply as 'limits/filters/standards' to 'identify/define/generate AI'.


## Optimality variable tests

- Tests that identify optimality variables like 'determinism/completeness/accuracy' of an AI model, and whether the AI model can identify optimality variables and identify optimizations to optimize for an optimality variable
- Tests that identify whether the AI model can identify optimal interactions between optimality variables (testing whether the AI model can identify and improve optimization variables, to identify the system of optimal interactions between interface variables, to apply as a filter of its decisions/solutions)


## Interactions with other models

- Tests that identify whether the AI model contradicts other AI models
- Tests that identify whether the AI model can identify the errors of other AI models and correct them, or identify its own errors and correct them


## Interactions with useful structures

- Tests that identify whether the AI model can identify/generate relevant graphs, interfaces, useful workflows, and other useful interface structures like useful definitions like the definition of relevance, with a minimum of info like the 'definition of an interface' given to it as an input
- Tests to identify the limits/interface structures of an AI model, like the minimum of info it requires to solve most problems it can solve, or the change types the AI model can generate/identify to identify what problems it can solve


## Other useful tests

- Tests that can be run on neural network architecture specifications and algorithm code to identify the 'probability distribution of error types' of an AI model without training/testing the AI model
