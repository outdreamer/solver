# AI Optimizations

It's useful to apply relevant graphs when optimizing AI.


## Identify relevant graphs

Identify relevant graphs for AI optimizations, like:
- graphs of 'mixed-specificity matrix or graph states' (like a specific relevant matrix or graph with both variable and constant components) and function structures/sequences applied to create changes to matrix states that 'stabilize/preserve or vary/scale some attribute (like "preserving a symmetry, while reducing variable count")' and optimized variants of these function structures/sequences (like the 'most stable function sequence or the most generally relevant function sequence') and interface metadata of these connection variants (like 'relevant thresholds/ratios of optimality') and optimized 'interactions between these optimized function sequences' (like 'causal/otherwise useful connections between matrix/graph changes')
- optimizations of the previous graphs of 'optimized connections between matrix/graph states' and 'optimized interactions of those connections/changes' like 'integrating other interface structures (like limits on change sequences) into the graph' and 'integrating variable structures (like variable combinations/sequences to optimize for) into the graph'
- graphs of 'high variation function sequences/combinations/structures (like derivatives/regression)' and 'intents enabled/metrics optimized by each function structure' and other interface structures (like 'related problems or general descriptions of function structures') and the 'relevance of those structures' (like the 'relevance of those intents') to identify 'directions of optimality on graphs of these interface structures of function structures'
- graphs of 'what is similar/different (across matrix transformations or graph optimizations)' and graphs of 'what would be useful/optimal if similar/different' and 'connections/useful directions between these graph sets' to generate 'useful changes to apply to a neural network type'
- graphs of 'optimal optimization structures (like optimization sequences without contradictions or changes in some metric)' and 'which function structures/sequences have applied some subset of those optimization structures/sequences', thereby identifying 'possibly relevant function sequences to apply the relevant optimization sequence to', and also 'graphs of optimization problems/solutions' like what 'difference/direction change in optimization metrics' to apply when an optimization metric is 'maximally optimized' (like how 'generality' reaches a relevant limit with 'abstract concepts or types of abstract concepts'), as a way of 'generating optimizations of neural network types' by 'identifying relevant optimization structures to apply, based on similarities/relevance to identified optimization structures/sequences' or 'identifying generally relevant optimization structures/sequences'
- graphs where 'errors have similarities (like similar type, a spectrum/connection of similar errors, similar error cause) identifying/generating some degree of incorrect similarity/difference qualifying as an error (like where weights decrease to zero)' so that solutions/optimizations can be formatted as 'changes to error structures/similarities' like 'invalidations of error spectrums' or 'opposing types to error types' or 'reversal of an error cause, across multiple error types resulting from that cause'


## Identify relevant structures in relevant graphs

Then identify useful structures in those graphs, as a way of 'identifying/generating new neural network types', like:
- 'commonly applied function sequences maintaining/increasing some optimization, above some ratio of the time'
- 'identifying limits on optimality with existing function structures in existing graphs (to solve with some more relevant graph, using new generated function structures, or to identify a possibility space generated from those limits, or identify new optimization metrics without identified limits)'
- 'missing optimization structures or structures that are never similar/different in these graphs (or other problem structures in these graphs)' to 'identify relevant optimizations of these graphs' which then can 'identify/generate new neural network types from the optimized graphs'
