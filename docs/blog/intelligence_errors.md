# Intelligence Errors


## Feelings

'Feelings' are a common source of intelligence errors. Feelings are 'overly simple, mostly irrelevant/false, relative status change indicators'. They are rarely useful for problem-solving, and should almost never be applied as a trusted indicator. 'Feelings' as in 'rewards/punishments' are a terrible learning method, compared to better alternatives like 'identifying relevant intents/possibilities/variation/optimizations/interface structures (identifying that some optimal intent is possible, or identifying a new source of variation, or identifying that an optimal point is adjacent, as a motivator)' and otherwise 'applying logic/info' ('logic/info' can change 'feelings/actions' and otherwise make them irrelevant). Feelings are 'indicators of simple previous successes/solutions' that are almost never relevant to the current situation.


### Inputs/causes

'False/irrelevant good feelings' can be caused by:
- a similarity to a group (an error is where the 'group is wrong, so being similar to the group is wrong')
- a previous/false/irrelevant success in a direction/position/structure (an error is where the 'direction is iterated to an irrelevant degree' or where the 'position has a more optimal alternative' or where the 'success is irrelevant/false')
- a lie (an error is where the 'lie is not even possibly/probably/otherwise relevantly true', so it shouldn't be applied as in 'acted on')

Similarly, 'false/irrelevant bad feelings' can be caused by:
- a previous error in a direction (an error would be where the 'success is the next position change in that direction')

'Relevant good feelings', by comparison, can be caused by:
- relevant intents like 'inventing a valuable new invention'
- relevant mental/physical exercise
- relevant high functionality/freedom/power (high ratio of solutions/ability to problems/limits)


### Advantages/disadvantages

- Thinking is capable of optimal intelligence variables like 'objectivity' and 'self-control', whereas feelings are almost completely incapable of optimal variables like 'objectivity' and 'self-control'
- Feelings-based methods are likelier to create extreme errors like 'sequences of lies that create insanity ("insane" as in "extremely wrong")' (like 'driving someone insane with lies that feel good')


### Solutions

This 'inaccuracy/irrelevance of feelings' makes rules like "regularly applying thoughts such as 'that is an intent, not what is true'" useful to 'correct errors of feelings'.


### Example comparison

Picture a graph of solutions/errors, where if an individual navigating the graph encountered an error, they would 'feel bad', but a solution might be right next to that error, so the 'relative bad feeling' would be 'irrelevant/false' in that situation. Now try to think of a 'feeling that would accurately guide an individual across the graph in a way that they only encountered solutions, without using thinking' (as in 'logic/info/other interfaces'). That's why feelings as in 'rewards/punishments' are a terrible learning method. They 'slowly, overly simply, indirectly, locally/specifically and otherwise falsely/irrelevantly' try to represent 'general relevance' by applying 'basic components of connections', without any 'definition of relevance' integrated ('arriving at the definition without knowing it, using simple/indirect/specific connections'). Simple/indirect/irrelevant 'rewards/punishments' can identify simple components of connections (connections between solutions/errors for example), but without interface analysis, these connections aren't organized/otherwise optimized by simple/indirect/irrelevant 'reward/punishment' methods on their own. Comparatively, think of the graph of the 'definition of relevance', and how this graph could 'probably identify the connections between solutions in a graph with trivial changes' (since the graph of the definition of relevance already connects solution/optimization structures). That's why 'relevant thinking' is more useful than 'simple/indirect/irrelevant learning methods (like rewards/punishments)'.


## Dependence on brain tricks/boosters

Brain tricks/boosters can be useful to 'jump start' thinking. 

For example, caffeine is a common 'brain booster' by increasing 'alertness' as in 'connectivity/scale/speed of thinking', which can be useful, and can likely change an individual with 'basic intelligence' to be more similar to those with 'intermediate intelligence' by increasing the 'scaling ability of their thinking' to a trivial degree.

However, 'depending on these brain tricks' is a common source of errors, as is 'over-use of these brain tricks' and other errors.

For example, frequently using a 'scaling booster' may make someone overly dependent on 'iteration' in their thinking, which is sub-optimal.

Another brain trick is 'thinking about already identified optimal structures (like already identified valuable inventions)'. This can be useful to 'jump start' creativity, but is dangerous to depend on, as depending on it can 'decrease creativity'. Creativity feels like 'new neurons being created, or new areas of the brain experiencing blood flow, or re-organization of the brain'. 'Applying this feeling as a relevant indicator of creativity' can be a useful way to correct the error of depending on this brain trick of 'applying identified inventions to jump start creativity' (meaning, when trying to think of a new invention, check if it feels like new neurons have been created yet, as an indication that 'relevant variation' is identified, to avoid an error of a 'decrease/lack of creativity' like a 'trivial iteration of an identified invention').

Other dangerous brain tricks to depend on or over-use or otherwise sub-optimally interact with:
- mental exercise ('using your brain', like with brain teasers/puzzles/games), as an input to 'jump start' the 'usage' function
- visualization (like 'drawing a graph') as an input to 'jump start' the 'automation' or 'organization' function ('structuring' is an input to 'automation' and 'organization')
- applying 'combinations' to 'maximally different variables' (like 'interface variables') as an input to 'jump start' the 'creativity' function
- applying 'simple structures' or 'similarities/differences' or 'concepts' as an input to 'jump start' the 'understanding' function
- applying 'optimization/solution/relevance structures' as an input to 'jump start' the 'optimization' function
- applying 'definitions/requirements' to 'jump start' the 'logic/inference/derivation' function
- applying 'changes to identified optimal structures to identify new optimal structures' to 'jump start' the 'creativity' function

More optimal brain tricks, that are less dangerous to over-use or depend on:
- applying relevant graphs, like the graph of the definition of relevance
