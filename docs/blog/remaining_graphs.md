# Remaining graphs

There are a few thousand relevant graphs identified in this repository (trivially generated by identified graphs, graph combinations, workflows, graph variables, or other interface structures), which can be applied as an input to various algorithms to generate other relevant graphs.

Once enough graphs are identified which are maximally different graphs, those graphs can be applied as 'base graphs' or 'limit graphs' or 'hub graphs' of other graphs, in a graph of graphs.

The point of these identified maximally different graphs is to enable identifying the remaining relevant graphs automatically, where the original set of identified relevant graphs acts as a 'guide' for defining/generating other relevant graphs, because the original set of relevant graphs implements a sufficient ratio/structure of the definition of relevance and implements sufficient specificity/other relevant variables, that the set of graphs can be applied as a 'boundary/limit/definition/constant/certainty' structure to filter other structures.
