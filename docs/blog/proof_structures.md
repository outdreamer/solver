# Proof Structures

Let's identify proof structures regarding a simple statement like 'type A is always bigger than type B'.

Proofs currently try to prove whether a statement is 'true in the current reality' (rather than answering questions regarding 'relative truth' like: 'could this statement be true in any reality and if so, which ones?' or 'should it be true?' or 'is it optimal for it to be true?' or 'is there an optimal way for it to be true?').


## Certainty/constant structures

Proof structures often try to connect/combine/add certainty structures:
- 'requirements/limits' like a 'requirement that type A is bigger than type B' or an 'insurmountable limit on the size variable for type A or type B or both'
- 'definitions' like a 'definition of type A that excludes any item that changes enough (in the size variable)'
- 'constants' like where 'the size variable of type A doesnt vary'
- 'implications' connected to 'sufficient relevant variables' to 'cover the possible variation of the original statement'
- certainty descriptions like 'every possible way this type could vary still doesnt overlap with type B'
- certainty causes like 'filtering false variants or filtering impossibilities (like every way this statement could be false/impossible have been filtered out)'

Proof structures can involve generating a 'subset of a specific graph that is relevant to the problem', like a 'graph of truth causes, or requirements, or causes of requirements (to identify if there is a requirement that a statement is true)' or a 'sequence of implications/assumptions (to identify whether implications of the original statement violate some relevance structure/area/boundary)' or an 'opposing contradiction vector to the vector representing the original statement (to identify contradictions)', applying the original statement as if it's true/certain.


## Uncertainty/variation structures

Uncertainty structures involve applying variation to the original statement (like 'differentiating types until there is a clear decision boundary'), to filter out uncertainty (like 'ambiguity'):
- position of variance to apply in the original statement (does 'always' vary? does 'bigger' vary? does 'type A/B' vary? does 'is' vary?)
- variants of the original statement: can relevant variants be proven (like a 'set of general/specific variants', implying that the original statement is true, by 'being a point in the range between true variants')
- 'identifying whether variation is required in relevant graphs to solve the problem' is a useful application of relevant graphs as 'base certainty structures to apply changes to in order to generate uncertainty structures like possible new relevant graphs (which are not optimized/integrated with other relevant graphs yet)'
- general patterns like 'truth structures are often optimal in some way' doesnt require that 'every real structure is optimal', but rather implies that it 'likely will be optimal for some metric at some point or will be optimal regularly or will change its optimality for some other metric than the solution metric, or it will stop existing', so these general patterns can be applied as 'approximations of certainty structures' (with lower certainty than actual certainty structures)

Generally relevant graphs like the 'graph of the definition of relevance' offer other lower certainty structures (components of relevance overlap with certainty, like 'validity'):
- "identify whether 'type A is always bigger than type B' on generally relevant graphs" is a useful intent to solve, that applies relevant graphs to approximate certainty
- "identify whether type A can be connected using optimization/solution/connection structures associated with a component of relevance like 'possibility'" is a way to apply a specific graph (the 'graph of the definition of relevance')


## Optimal proof structures

Optimal proofs (the most useful types of proofs) could implement descriptions like:
- applying high certainty graphs: 'being able to trivially query a causal graph (bc the causal graph is complete, indicating all relevant causal connections across problems)' ('causality' being 'more identifiable/certain in many cases')
- applying conceptual understanding: 'being able to identify/generate relevant (valid) concepts to connect to solve any problem' is an optimal proof structure
- applying graphs with realistic (or 'certain/relevant') variation/other interface variables: identifying relevant graphs that 'contain enough variation to solve any problem (like varying/interacting with/comparing any problem enough to solve it, where any problem is representable in some subset of the graph structures)'
- some structures are more true than others (like the original statement might be true 'up to n additional abstraction levels of each type', which has 'relevant abstract variation'), so matching 'proof structures' with the 'probable truth range/structures of a statement' is useful (to apply 'generalizations of the statement' as an 'alternate statement to prove', only 'up to the n abstraction levels' for that statement)
