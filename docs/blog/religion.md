# Religion

Religious structures like heaven/god can have real counterparts.


## Immortality

Immortality can be achieved by inventing something that:
- is forever relevant (still used/relevant at the end of time)
- generates relevant variation, like other relevant inventions
- implements the definition of relevance/optimality/meaning
- connects other realities/universes to increase the 'relevant lifespan of an invention', beyond the definition of time in this reality/universe
- causes the end of time (makes time irrelevant)
- causes immortality as in 'permanent stability of relevant variation' of a life form (finding some structure supporting permanent relevant variation, like an optimized set of relevant graphs that is always updating/optimizing itself)


## Miracles/magic

Miracles are seen as:
- extreme good luck
- an extremely good event

Magic is seen as:
- extreme power, like the power to generate efficiencies/optimalities to make some intent trivial/relevant
- an extremely trivial/efficient/otherwise relevant implementation of an intent

So miracles can be seen as 'optimal points/structures' and magic can be seen as 'optimality implementations (like efficiency implementations)'.


## God

God is an entity that:
- can cause/control any change/variable, such as changing reality or the future
- can generate other religious structures, like heaven/luck/randomness
- is often seen as equivalent to luck/randomness, but would control other interface variables as well


## Angels

Angels/saints are seen as:
- optimizing for some metric
- having some specific power

These simple optimization structures can be integrated into more optimal/realistic (such as more complex) optimization structures, like generating multiple gods with equivalent power, or having a brain that reflects the structure of optimality/heaven.


## Heaven

Heaven is an optimized place where:
- 'individuals fulfilling some optimization metric' can have their 'intents optimized (as in made trivial/costless)' forever, which is unlikely to reflect normal human intents (which contradict each other), unless heaven is distributed and simulated in their minds to avoid these 'contradicting intents (like everyone wanting to be in charge)'

Intents like 'common human intents' are unlikely to be optimized for in a real heaven, bc the normal human attention span is easily optimized/hypnotized/controlled, and is unlikely to reflect reality/optimization, so 'real intents (like solving/optimizing reality)' are more probably optimized for in a 'real heaven'.

A place implementing 'optimization rules' can qualify as heaven.


## Sacred

What can be considered sacred could include:
- requirements for fulfilling reality intents like 'solving reality' or 'maintaining/increasing relevant variation' (like a sacred 'set of optimization rules/definitions')
- the most powerful structure that is most likely to be capable of fulfilling these reality intents


## Reality

Reality is:
- an experience of relevant variation by some set of conscious life forms
- a structure where 'relevant variation' can occur (so 'relevant graphs' qualify as a 'reality', given that they support the most relevant variation)


## Judgement Day

A point in time where a function like 'test/analyze/evaluate/judge' is applied to some optimization structure (like 'solution metrics (individual virtues)').

Other 'functions/variables' determining 'points in time' include:
- doomsday: a 'point in time' where 'evil wins' is a temporary loss for what will ultimately be more stable, which is goodness
- singularity points: the 'end of problems/other interface structures' can be triggered by optimization structures (like 'computers/algorithms')


## Perspective Battles

Good vs. evil and other perspective battles (like between different religions) are optimization problems:
- 'goodness' is generated by intelligence/optimality, so it will win against evil (which is an 'outdated suboptimal optimization structure')
- 'different sets of priorities that can co-exist' will win against for example 'priority sets that require that no other priority sets exist'


## Variables of religious structures

Variables of these structures to be used (to generate variants of these structures) include:
- possibility (allowed by definitions reflecting reality)
- interactivity with physics structures (directly connectible to real structures like realities)
- uncertainty (having sufficient relevant variation in the definition to be uncertain)
- optimality (optimizing power centralization in one entity, or optimizing a place, etc)
