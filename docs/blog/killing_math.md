# Killing Math

Is math about to be over as in 'completely solved', given the state of technology?


## Solution Metrics

What are some metrics indicating that math is 'completely solved'?
- all new problems can be trivially/otherwise relevantly solved with identified concepts/variables/similarities/other interface structures of math
- all new problems are 'subsets/components/abstractions/extensions of or otherwise similar to' solved problems
- all relevant graphs have a completely specified/defined connection to the math interface
- the 'subset of a relevant graph that has already been generated/specified' can be extended/applied to solve all new problems (like 'applying a new layer in a relevant layer graph solves new problems')
- there is a relevant graph set that connects every relevant math structure (like a graph that connects every relevant number type or important number)
- there is no relevant variation left to describe/solve/make certain/verify/test
- there is a relevant graph of all relevant solutions/connections that either 'covers all solutions, or can be trivially/otherwise relevantly varied to identify all solutions'
- there is no contradiction in a set of definitions, and this set of definitions contains enough variation to describe/identify/predict all possible independent math variable connections 
- all new problems are identified/defined/described/represented in a format that is possible to connect to a 'relevant graph query' to solve each problem
- the limits/requirements/constants/certainties of math are identified/defined/described/represented on some graph


## Remaining Intents

What are some intents left to solve for, that will increase the percentage of solved math problems?
- 'identifying/optimizing/organizing/applying all relevant graphs' and 'connecting relevant graphs to the math interface' are the primary optimal intents to solve (given how useful relevant graphs are and how trivial connecting these to the math interface is at this point)
	- 'identifying missing/inaccurate/otherwise problematic variation in relevant graphs' and 'solving these graph errors' is a subset of these intents
	- similarly, 'identifying the optimal graph of relevant graphs' is an alternate intent of these intents
- 'identifying which problems are the optimal problems that should be solved in math' (identifying the problems that, once solved, will solve all other problems by proxy, like where all remaining problems are a subset/generalization/variant of solved problems)
- 'identifying/generating relevant graphs of interface structures on the math interface' and 'identifying interface structures on the math interface' are an alternate set of intents to solve


## Relevance

So whether math is about to be 'completely solved', depends on:
- whether the relevant intents are successfully computed in the right sequence/priority/structure, with the right implementation (like the right definitions/assumptions), to the right degree/structure
- whether the solution metrics are complete/otherwise optimized

What does 'completely solving math' mean?
- once 'math is solved', 'physics/reality' will be trivial/relevant to solve next (bc 'identifying what numbers are possible to connect' determines 'what connections/variables/structures can occur in reality')
- once 'math is solved', it can be identified whether math can be changed/optimized, whether there are alternate math systems that could exist with different definitions/assumptions/constants/certainties, and other interface structures of math
