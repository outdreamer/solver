# AI Descriptions

Different descriptions of AI make different info like 'relevant intents' trivial to identify.


## Example AI descriptions

A 'network of functions':
- this description makes it trivial to identify that 'graphs can solve problems' and 'there are likely other useful graphs for solving problems than neural networks'

A 'weighted network of functions, to find a solution function':
- this description identifies 'identify other graph variables' and 'identify other solution formats than a function (like a graph)' and 'identify other useful structures to identify like other function types' as relevant intents

A 'learning function':
- this description makes it trivially identifiable how there are other important intents to implement in 'solving AI', including 'identifying the right graphs to apply learning functions on' and 'optimizing for alternate functions to learning (like test/derive/infer)'.

A 'learning function on a 3d graph':
- this description makes it clear that intents like 'standardize a problem to these three variables' need to be implemented first before this 'learning function type' can be useful

A 'learning function for a problem type':
- this description makes it clear that related intents like 'identifying a learning function for other problem types' need to be implemented as well

A 'learning function, to learn optimization':
- this description makes it clear that 'learning specific info' is relevant as opposed to 'being able to learn anything, if given enough memory/time'

An 'optimal learning function':
- this description makes it clear that it's important to implement intents like 'define/identify optimality' and 'apply that definition to optimize learning functions (optimize by making the function useful across different intents or otherwise optimal'

Other intents identified by AI descriptions:
- 'identify a function to learn anything on any relevant graph (given the same set of initial definitions/assumptions/interface structures) within a reasonable amount of time and with reasonable memory usage'


## Example applications to other fields

Similar to AI, these 'description/intent sets' can be used to determine how to solve other fields:
- describing math as a 'set of problem types' identifies that it's useful to 'identify relevant interactions between problem types' to 'identify important problem types to solve', as opposed to just 'generating a learning function' (without guaranteeing that it will be optimally applied)
- describing math as a 'set of independent variables' identifies that it's useful to 'identify new/relevant independent variables (like new relevant graphs)' and 'identify trivial/optimal connections between independent variables (like optimal organizing graphs of relevant graphs)'
