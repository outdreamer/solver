# Optimal Implementations

Optimal implementations of a solution can vary so much that 'identifying the optimal implementation, before implementing to a degree' is a useful intent.


## Definitions

Sub-optimal implementations:
- have errors that 'can be fixed without compromising a solution/optimization metric, if some relevant intent is solved for'
- are often trivial to identify, like by being a 'simple/adjacent combination of existing implementation strategies/structures'
- frequently have errors of 'not applying interface analysis' to 'think it through', like to 'identify limits of the usefulness of a structure'
- frequently are incomplete, because of some error like an 'over-prioritization' of 'simplicity'
- frequently simply apply potentially irrelevant metrics like 'scalability' without integrating other metrics like 'generality/reusability'
- apply incorrect inputs to implementation, like incorrect assumptions/definitions or suboptimal implementation strategies, that have wide-ranging impacts on the implementation optimality

Optimal implementations:
- often implement multiple useful intents
- have errors that are 'trivial/otherwise irrelevant'
- are stable across varied inputs


## Examples

Sub-optimal implementations
- sub-optimal implementations of interface analysis would 'simply identify interface structures like filters/connections/differences' and 'connect them in simple graphs of the same type'

Optimal implementations
- an optimal implementation of interface analysis would apply iterations of interface analysis until 'relevant graphs are identified and integrated', then apply 'degrees of interface analysis' to relevant graphs to identify any possible new relevant graphs required to solve a problem, as indicated by the 'degree of complexity', and would check existing optimization structures like 'implementations of optimization metric combinations' for optimization strategies/structures specific to those optimization metric combinations/structures


## Why identify optimal implemenations

Think of the cost of implementing neural networks incorrectly or otherwise suboptimally, like when the technology was not developed and errors were not identified for early implementations.
Trillions have been spent on suboptimal implementations, when billions would have identified optimal implementations.


## Optimal implementation strategies

Optimal implementation strategies include:
- apply at least three degrees of interface analysis, for human interpretability and a realistic degree of complexity
- identify and apply relevant graphs, to simplify analysis as much as possible, so that fewer degrees of interface analysis applications are required to identify accurate similarities/differences
- identify optimal conceptual interaction points for maximal understanding, and implement solutions with these optimal points as regularly applied validations
