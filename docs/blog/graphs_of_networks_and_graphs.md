# Graphs of Neural Networks and Graphs


## Similarities between graphs and neural networks

Graphs and neural networks have similarities like:
- common core/generative structures (vectors, nodes, functions, layers, positions like starting positions, sequences, connections)
- common structures described/implemented/applied (interface structures like cause, change, similarities are described/implemented/applied by neural networks and graphs)
- both connect specific structures like 'numbers/vectors/multiplication/sequences' to emergent interface structures like 'cause'
- both can be optimized to make some intents more trivial to solve on the graph/network

These similarities can be used to generate graphs of neural networks and graphs to identify overlaps/other similarities.


## Differences between graphs and neural networks

A graph requires:
- identifying similarities/differences and applying them to create a distance/difference function to determine node positions

A neural network requires:
- applying a similarity of inputs like a 'adjacent subset of inputs' as a defined/required similarity that can be assumed
