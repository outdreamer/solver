# Mind interactions

It's useful to define mind components and identify current/optimal mind component interactions.


## Memory

The memory is very limited in usefulness, because optimal intents like 'derive/infer/create' don't require a lot of memory.

However, it's nevertheless useful to store useful structures like 'relevant interface structures (graphs, starting points, queries, definitions)' in memory to avoid re-learning.

Memory can itself act as a limit, when an individual uses their brain to 'quickly solve problems' rather than 'optimally solving problems', in which case they will be incentivized to use their memory rather than creativity/curiosity/other mental functions, which makes their brain extremely weak/dependent on what they read/learned.

Memory doesn't guarantee 'understanding of what is remembered', where 'understanding' involves 'optimal organization'.

Memory is a source of errors like 'bias', so 'minimally depending on memory' is an optimal intent.


## Conscious

The conscious mind has important limits to identify, like 'how much consciousness it can have (as in what ratio of neurons can be active, what info those neurons can connect, etc)' and other limits on variables of consciouness, which are important to identify, because consciousness is the likeliest structure to solve reality given its potential, so identifying "what it's capable of and what it can't implement" is important.

The conscious mind has limits resulting from its suboptimal interactions with other mind components, limits like 'bias/assumptions/defaults', which are important to ignore/oppose, so that 'objectivity' can be implemented in the conscious mind though strict filtering/optimization of mind component interactions.

Consciousness can be stored in memory (identifying an optimal structure and storing it in memory is like 'storing a unit of consciousness').

Consciousness is theoretically capable of 'identifying/otherwise interacting with reality' (consciousness may be capable of the 'level/structures of complexity/variation/interface variables' that reflect reality).

Consciousness can support advanced mind interactions like 'meta-mind interactions' and 'mind interaction optimization'.

The 'ratio of decisions/freedom/potential' in the conscious mind can be optimized to some degree/structure, with optimizations like 'learning interface analysis' or 'thinking about thinking'.


## Subconscious

The subconscious acts like a 'random function' because it does an incomplete/suboptimal job of intents like 'aggregating/organizing important/recent/common memories/solutions' and 'generating relevant feelings'.

The subconscious is another source of errors like 'bias', and can propagate its inputs to other mind components, so it's important to filter out the subconscious which is a 'suboptimal aggregator of an over-simplified definition of relevance'.


## Mental disorders

Disorders like schizophrenia/anxiety/depression/ADHD have their advantages, like:
- focusing on problems/logic (anxiety/depression involve focusing on problems, and schizophrenia involves focusing on logic like the 'logic of conversations/debates'), though 'focusing on these structures' doesn't mean 'solving/optimally using/optimizing these structures'
- emotional control as a requirement and therefore a probable output (controlling negative emotions is a required survival skill for disorders like depression/anxiety)
- ADHD involves 'required variation' which makes it useful as an input to curiosity/creativity (though curiosity/creativity is the best-case output of ADHD, and not a required output)


## Mind usages

Different ways to use the mind include:
- prioritizing sequences of queries to different mind components (for example, a common suboptimal sequence is 'first check the memory, then the subconscious instinct, then other components')
- 'simple brain graph queries' similar to 'bouncing any new structure within a simple graph of limits/checks' is a 'common suboptimal way to apply mind components' (like a common suboptimal brain query would be 'check for a simple contradiction, check if it is possible, check if it feels good, check common variables/opposites')
- 'complex brain queries' like 'identify optimal graph-neuron interactions' like 'apply a relevant graph sequence' (like 'apply the definition of relevance to check if this is real new variation, or if it fits an identified structure, then try to generate a new graph based on the variation, then try to integrate the new graph into other graphs, then re-organize the set of relevant graphs')

What do these interactions mean?
